## Not measured offline

- Whether the real LLM actually stays silent when it should (the stub model always answers; 'engaged' only means the router called the model).
- Reply quality, persona fit, factual correctness, latency and cost.
- The backend layer: WeChat dedup, message-burst coalescing, real is_at_mentioned / is_reply_to_bot detection (taken from the case as given).
- Real group traffic: the proactive rate window only sees the messages in a case's context, and gate streams are synthetic Poisson arrivals.
- Vision, web search and memory consolidation content (stubbed offline).
- A live run needs an API key and a WeChat account; no live mode is implemented here by design.

Reproduce: `python -m evals.run_offline --seed 7` (writes this file and the JSON next to it).
