联调发现、已经改好的

  1. 机器人自己发的回复被当成「运营亲手回复」，每发一条就转人工 5 分钟Mac 已挡住根子请同事在 Windows 修
  2. 东莞、中山这类没有区县的地址，聚水潭建不了单已改：区县必填，填镇 / 街道 / 新区，预览就拦
  3. 话术写死「3 天内寄出」已改：只说审核后尽快安排，寄出后发物流单号
  4. 建单后那句「寄样单建好啦🎉 单号…」像我们占了便宜已改：先谢谢老师、说给老师安排上了，不发内部单号
