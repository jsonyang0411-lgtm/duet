达人寄样流程现状

真跑过 离线测过 待做 要你点头 真跑过 = 在真实账号 / 平台上跑通；离线测过 = 自动测试覆盖，还没在真实环境跑
达人在微信里发消息
Windows收发微信（同事那边的微信边缘）
Mac · Claude读知识库、商品目录、案卷，起草回复或平台动作
你 · 控制台「待审批」里发 / 改了再发 / 不发 / 批准
平台聚水潭建寄样单，百应 / 小红书开专属佣金

一找达人

  1. 1

    在聚水潭按条件找达人，加进「我的达人」

    按销售额、粉丝数、带货等级筛；抖音、小红书都能找（小红书看直播场均）。你定条件，我用命令行查，加进达人库要你同意。

    真跑过 · 已加 8 位加入要你同意

二第一次联系

  1. 2

    抖音达人：百应发「邀约带货」卡片

    卡片上写我们免费寄样、包邮，留我们的微信，请达人加微信聊。平台显示的「买样 / 免费申样」不用管。

    真实预览跑过卡片上的微信号 / 手机号待定发卡片要你批
  2. 3

    小红书达人：聚水潭「查看联系方式」拿微信号，手动加

    邀约卡片只有抖音有。

    你来加

三加上微信，进名单

  1. 4

    控制台「达人名单」里加上他，填抖音号 / 小红书号

    系统自动去聚水潭查档位、主播类型、平台 UID，写成「达人资料」给 Claude 看（每天重查一次）。

    离线测过达人加微信后自动进名单：等同事的探针

四微信里聊天（核心）

  1. 5

    达人发消息 → Windows 收到 → Mac 上的 Claude 起草回复

    起草时读：知识库（合作政策、话术、商品）、商品目录（抖店 900 款、小红书 939 款）、这位达人的案卷和达人资料。

    离线测过起草质量：4 个场景离线试过都对
  2. 6

    你在「待审批」里审每一条：原样发 / 改了再发 / 不发

    • 你改过的话，下一份草稿照你改后的说法写。
    • 你直接在微信里回达人，系统自动转人工接管，这段时间不起草。
    • 寄几款看档位，佣金比例不说，钱的事转你。
    离线测过等 Windows 接上联调每条都要你审

五挑款、建寄样单

  1. 7

    达人挑好款和颜色尺码、确认收件信息 → Claude 起草寄样单

    控制台显示预览：达人、商品和规格、快递（中通）、地址（手机号只显示〈手机1〉这样的占位）。预览只读聚水潭，不建单。

    离线测过聚水潭预览真跑过
  2. 8

    你批准 → Mac 在聚水潭建寄样单 → 把「寄样单建好啦，单号 YP…」发给达人

    建单时把达人认领到你的子账号、地址存到他名下；建完按单号读回核对。每张单只执行一次。

    建单真跑过 · YP2610272378025（测试，已拒绝）要你批准
  3. 9

    仓库在聚水潭「寄样管理」审核，审核通过才发货

    仓库 / 你

六开专属佣金

  1. 10

    寄样单建好后，系统自动叫 Claude 起草开专属佣金

    20% 起步（最高 25%，代码里写死），一次开一款；抖音用达人资料里的 UID。

    离线测过
  2. 11

    你批准 → Mac 在百应 / 小红书开好 → 最后一款开好时通知达人

    百应的专属佣金第二天 0 点生效。通知不说比例，达人在选品里能看到。

    开、关专属佣金真跑过（测试 10%，已关）要你批准

七发货以后

  1. 12

    合作单里填运单号 → 系统起草发货通知 → 你审后发出

    离线测过运单号从聚水潭自动带回
  2. 13

    签收后跟进带货：发视频或开直播、看数据，决定要不要加佣金

    加佣金由你定
  3. 14

    寄样结束 90 天后，系统自动清掉收件信息

    离线测过

你点头的地方

  1. 每一条发给达人的回复
  2. 寄样单
  3. 专属佣金
  4. 邀约卡片

现在所有往外写的动作都要你点头。以后做熟了可以放权，例如专属佣金连续几次原样批准后改成自动。
