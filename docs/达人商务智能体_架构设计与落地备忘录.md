## 一、 核心死穴攻坚：破除“Claude Code（CC）直接当服务器”的工程误区

### 1. 同事碰壁与被拦截的技术真相
* **工具定位冲突**：Claude Code（VS Code 插件或终端 CLI）的本质是**“人类工程师的交互式结对编程助手”**，而不是**“7x24小时后台服务守护进程（Daemon）”**。
* **权限拦截死锁**：Claude Code 内部具备严格的人机交互确认机制（Human-in-the-loop）。当它尝试执行外部命令（如调用小红书 CLI、调接口发微信）时，必须由人类在控制台手动敲回车确认；在局域网自动化调用（非 TTY 管道）中，会直接报错 `Permission Denied`、命令超时或挂起。
* **事件驱动错配**：CC 适合“接到一个复杂任务 $\rightarrow$ 查代码 $\rightarrow$ 解决并退出”；而微信达人沟通是“全天候待命 $\rightarrow$ 随时收到消息 $\rightarrow$ 毫秒级响应并维持上下文”的事件驱动架构。

### 2. 向老板汇报与落地的“破局正解”
* **理念调整**：**“用 Claude Code 编写智能体，而不是把 Claude Code 挂在微信上当服务器”**。
* **架构方案**：
  * **开发态（Dev-Time）**：你们依然在 VS Code 插件或终端里使用 Claude Code，由 CC 来作为主力架构师和程序员，编写、调试整个系统的 Python 后台代码；
  * **运行态（Run-Time）**：实际在 Mac 后台跑的是一个轻量级常驻服务（如 `fastapi` + `anthropic` SDK）。它直接调用 Claude 官方 API 接口，摆脱 IDE 插件的弹窗拦截，实现真正的 7x24 小时全自动静默调度。
* **向上汇报话术**：
  > “我们整套智能体内核完全由 Claude Code 架构与生成，使用的是 Claude 最顶尖的底层推理大脑，同时根据生产级工程标准做了服务端容器化，规避了 IDE 客户端对高并发指令的安全拦截，确保了 7x24 小时无人值守的稳定性。”

## 二、 5 大核心维度确认现状与技术决议表

| 维度 | 当前决议与技术选型 | 落地实施细节与关键策略 |
| :--- | :--- | :--- |
| **1. 链路通信** | **双向通信已打通**<br>Win 本地转文字（ASR） | • **Win $\rightarrow$ Mac**：传输标准化 JSON（含文本、达人微信ID、时间戳）；<br>• **Mac $\rightarrow$ Win**：Mac 完成决策后，调 Win 端本地 HTTP 接口反向驱动微信发消息；<br>• 语音在 Win 端本地转文字，避免了跨机大音频传输的高延迟。 |

| **3. 资质裁决** | **小红书粉丝 + 点赞破千**<br>不符者委婉拒绝 | • **前置过滤规则（确定性代码）**：抓取达人主页数据，若未达标（粉丝数/近期图文点赞未破千），直接触发柔性话术（如：“亲亲，目前该批次体验名额已满，后续开放新一轮合作第一时间通知您哦~”）；<br>• **达标者**：进入深度意向沟通与样品匹配。 |
| **4. 审批闸门** | **“凡花钱必拦截”（Gate Hook）**<br>库存不足转人工 | • **原子行动数据包**：Agent 准备好“达人资质 + 申请SKU及库存 + 拟设佣金 + 寄样成本”，生成审批卡片；<br>• **严格防白嫖**：未获运营人工批准前，系统绝对禁止调用聚水潭发货，也禁止在小红书绑定佣金；<br>• **异常熔断**：缺货或接口失败时，自动通知运营介入人工协商。 |
| **5. 数据基座** | **轻量化嵌入式存储起步** | • 暂不引入复杂的外部 PostgreSQL；<br>• 采用本地单文件 **SQLite + WAL 高性能模式** 记录达人沟通历史与履约状态，后期可一键平滑迁移至云端 Postgres。 |

## 三、 个人微信防封高压线（专属风控指南）

由于使用的是个人微信号，系统必须内置以下拟人化风控拦截器：

1. **加好友与打招呼频控硬上限**：
   * 单日主动搜索添加 $\le$ 15 人，被动通过 $\le$ 30 人；
   * 每两次添加动作间隔必须引入随机抖动（如 180s ~ 450s 随机等待）。
2. **拟人化打字延迟**：
   * 收到达人消息后，**严禁 0.1 秒秒回**（极易被检测为外挂机器人）；
   * 根据待回复文本长度，动态计算延迟：`回复延迟 = 基础等待(3~6秒) + 字数 * 0.2秒`。
3. **话术去重与动态改写（Anti-Fingerprinting）**：
   * 严禁给所有达人发送完全一致的欢迎语或商品推介话术；
   * 调用 Claude 对标准话术进行同义微调改写，消除批量群发指纹。
4. **夜间免打扰与休眠**：
   * 23:00 至次日 08:30 自动进入静默模式，达人留言自动记录在次日晨报中，不触发自动化高频互动。

## 四、 核心代码架构蓝图（Mac 端常驻服务原型）

```python
# architecture_preview.py - Mac 端后台常驻调度器骨架
import asyncio
from typing import Dict, Any

class InfluencerAgentDaemon:
    def __init__(self):
        # 1. 初始化数据库 (SQLite WAL模式)
        self.db = init_sqlite_db()
        # 2. 挂载工具
        self.jst_erp = JuShuiTanClient(app_key="...", app_secret="...")
        self.xhs_cli = XiaohongshuCLI(bin_path="/usr/local/bin/xhs")
        self.win_gateway = WinWeChatClient(base_url="http://192.168.x.x:8080")

    async def on_wechat_message(self, event: Dict[str, Any]):
        """Layer 2: 接收 Win 端发来的标准化事件"""
        user_id = event["wx_id"]
        text = event["text"]

        # Layer 7: Defend - 外部文本视作数据，严禁直接作为系统指令执行
        sanitized_input = self.defend_prompt_injection(text)

        # Layer 1: Context - 读取达人历史档案
        profile = self.db.get_or_create_influencer(user_id)

        # Layer 3: Judge - 研判意图 (咨询 / 索样 / 闲聊)
        intent = await self.judge_intent(sanitized_input, profile)

        if intent.type == "SAMPLE_REQUEST":
            # 达人资格初筛 (粉丝 & 赞藏门槛)
            if not self.check_qualification(profile):
                await self.reply_soft_reject(user_id)
                return

            # Layer 5: Prepare - 后台静默准备 (查聚水潭库存 + 拟定佣金)
            sku_info = await self.jst_erp.check_stock(intent.requested_product)
            commission_plan = self.calculate_commission(profile)

            # Layer 6: Gate - 凡花钱动作，绝对拦截！生成原子审批包
            action_packet = {
                "influencer_id": user_id,
                "sku_id": sku_info["sku_id"],
                "stock": sku_info["quantity"],
                "sample_cost": sku_info["cost"],
                "proposed_rate": commission_plan["rate"],
                "address": intent.extracted_address,
                "status": "PENDING_HUMAN_APPROVAL"
            }
            # 存入待审核队列，推送通知给运营
            self.db.create_approval_task(action_packet)
            await self.notify_operator_approval(action_packet)

    async def on_operator_approve(self, task_id: str):
        """运营在审批界面点击【通过】后，触发不可逆原子操作"""
        task = self.db.get_task(task_id)
        # 1. 聚水潭建赠品单发货
        order_res = await self.jst_erp.create_sample_order(task)
        # 2. 小红书 CLI 绑定专属佣金
        await self.xhs_cli.bind_commission(task)
        # 3. 反向调 Win 端微信，给达人回传喜讯与单号
        await self.win_gateway.send_text(
            to_user=task["influencer_id"],
            content=f"样品已为您安排寄出！运单号后续同步给您，合作愉快~"
        )
```
